## 1. El problema

**Título del proyecto:** Programa de gestión de inventario para un deposito/almacen

**Descripción del problema:** El programa consta de varias herramientas implementadas en funciones para resolver el problema de tener que llevar la cuenta manualmente de los stocks y poder tenerlo separado en varios recursos distintos (hojas de papel, anotaciones, etc). Gracias a varias herramientas se puede lograr centralizar toda la informacion y acceder a esta de manera mas comoda para el usuario.

Además el programa genera una lista de movimientos muy util para cuando el usuario (el dueño) deba analizar los movimientos hechos en cierto periodo de tiempo pudiendo controlar exactamente que entra y qué sale.

**Por qué es un proyecto integrador:** Varias partes del incurso forman parte de nuestro proyecto tal como listas, diccionarios, algoritmos de ordenamiento para poder ordenar segun el nombre de los productos, manejo de archivos y sobretodo archivos binarios.

## 3. Cómo ejecutar el programa

**Requisitos:** Python 3.10 o superior

**Ejecución:**

```
python src/main.py
```

La entrada esperada por el programa es puramente de teclado, interactuando con el menu
