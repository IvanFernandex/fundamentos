Algoritmia y Programación con Python — Introducción al curso

1. ¿Qué es un Algoritmo?

La Real Academia Española define algoritmo como "conjunto ordenado y finito de operaciones que permite hallar la solución de un problema". Su raíz histórica remonta al matemático, astrónomo y geógrafo persa Al-Hwarizmi (780–850), considerado padre del álgebra e introductor del sistema de numeración arábigo en Occidente. La latinización de su nombre —y posteriormente la forma castellana medieval alguarismo— dieron origen a la palabra que hoy usamos.

Esta etimología no es trivial: Al-Hwarizmi presentó la primera solución sistemática de ecuaciones lineales y cuadráticas mediante una lista bien definida, ordenada y finita de operaciones. En ello está la esencia de lo que hoy llamamos algoritmo.

Propiedades fundamentales de todo algoritmo

  • Finito: debe terminar después de una cantidad finita de pasos.
  • Definido (no ambiguo): cada paso debe estar especificado con precisión, interpretándose de una única manera posible, independientemente del contexto.
  • Efectivo: cada operación debe ser ejecutable en un tiempo finito por un agente (persona o máquina) con los recursos disponibles.
  • Con entrada/s y salida/s: puede recibir cero o más datos iniciales y produce uno o más resultados.

1.1. Algoritmos en la vida cotidiana

Los algoritmos no son exclusivos de las computadoras. Cualquier procedimiento que resuelva un problema siguiendo una secuencia de pasos bien definida es un algoritmo. Ejemplos cotidianos incluyen recetas de cocina, partituras musicales, instrucciones de armado de muebles, o los pasos para operar un microondas.

1.2. Ejemplo clásico: el Algoritmo de Euclides

Uno de los algoritmos más antiguos conocidos es el de Euclides para encontrar el Máximo Común Divisor (MCD) de dos enteros positivos. Fue descrito en los Elementos (~300 a.C.) y sigue siendo la base de muchos algoritmos modernos en criptografía y teoría de números.

Algoritmo de Euclides — MCD(M, N)

Datos: M y N, dos enteros positivos
Paso 1: Dividir M entre N; llamar R al residuo
Paso 2: Si R ≠ 0, entonces asignar M ← N y N ← R, y volver al Paso 1
Paso 3: Si R = 0, el MCD es el valor actual de N. Fin.

Traza del algoritmo con M = 48, N = 60

IteraciónMNR = M mod N¿R = 0?
1486048No → M=60, N=48
2604812No → M=48, N=12
348120Sí → MCD = 12

Esta traza ilustra un principio clave: una vez hallado el algoritmo, la resolución del problema se reduce a seguir sus pasos mecánicamente, sin necesidad de comprender la teoría matemática que lo sustenta. En cierto sentido, el algoritmo representa la inteligencia requerida para resolver el problema.

2. De los Algoritmos a los Programas

Un programa de computadora es un algoritmo representado en un lenguaje de programación para que una computadora pueda ejecutarlo. Desarrollar un programa implica dos etapas inseparables: descubrir el algoritmo (la parte más creativa e intelectualmente exigente) y luego representarlo en la sintaxis del lenguaje elegido.

🎯 Idea central del curso

La actividad más importante y difícil en el desarrollo de software es descubrir los algoritmos. El lenguaje de programación es solo el medio de expresión. Por eso la algoritmia debe basarse en el proceso de resolución de problemas, no en memorizar la sintaxis de un lenguaje.

2.1. Las fases de Pólya para resolver problemas

El matemático húngaro George Pólya definió a fines de los años cuarenta las fases del proceso de resolución de problemas, que siguen siendo los principios en que se basan los métodos actuales. Estas fases no son lineales: se recorren una y otra vez en forma evolutiva, retrocediendo cuando es necesario, hasta que la solución sea satisfactoria.

1

Análisis

Entender el problema y definirlo claramente. Identificar qué se conoce, qué se busca, y cuáles son las condiciones y restricciones.

En programación: analizar casos de prueba representativos que permitan comprender el problema antes de intentar resolverlo.

2

Diseño

Idear un plan: cómo un procedimiento algorítmico podría resolver el problema. Determinar los recursos a utilizar y probar el algoritmo sobre papel.

En programación: diseñar mediante refinamientos sucesivos (divide y vencerás), expresando la solución en pseudocódigo.

3

Codificación

Llevar a cabo el plan: representar el algoritmo en forma de programa, expresando las acciones primitivas en la sintaxis del lenguaje de programación.

En programación: el último refinamiento; convertir el pseudocódigo en instrucciones Python ejecutables.

4

Evaluación

Verificar la eficacia (¿produce los resultados correctos?), examinar su eficiencia (¿usa los recursos razonablemente?) y analizar su potencial para resolver problemas similares.

En programación: pruebas con distintos datos testigo, incluyendo casos límite y casos de error.

2.2. Estrategia de diseño: Divide y Vencerás

La estrategia más común para desarrollar algoritmos es la denominada divide y vencerás: descomponer el problema principal en subproblemas más simples, que a su vez se siguen descomponiendo hasta llegar a un nivel en que los problemas sean resolubles por acciones primitivas de la computadora. Este proceso se llama de refinamientos sucesivos o diseño descendente.

Pseudocódigo: lenguaje puente

El resultado de los refinamientos sucesivos es un conjunto de instrucciones expresadas en pseudocódigo: un lenguaje híbrido entre el lenguaje natural y un lenguaje de programación. El pseudocódigo no es ejecutable directamente por la computadora, pero sirve como documentación interna del programa y como etapa previa a la codificación.

Los enunciados en cualquier nivel de refinamiento deben ser:

  • No ambiguos: interpretables de una única manera, independientemente del contexto (libres de contexto o autocontenidos).
  • Ejecutables: traducibles a operaciones que la computadora puede realizar (entrada, almacenamiento, procesamiento, salida).

4. Variables y Tipos de Datos en Python

Los datos que un programa manipula deben tener un nombre (para poder referenciarse en el código) y un dominio (el conjunto de valores que pueden tomar). En programación, estos recursos se denominan variables. Los valores que no cambian durante la ejecución del programa se denominan constantes.

4.1. Identificadores en Python

Reglas para nombres de variables

  • Deben comenzar con una letra (incluidas ñ, Ñ y vocales acentuadas) o el carácter de subrayado (_).
  • Pueden contener letras, dígitos decimales (0-9) y el carácter _.
  • El tamaño es ilimitado.
  • Python es sensible a mayúsculas y minúsculas: total, Total y TOTAL son tres variables distintas.

Recomendación de estilo

Use nombres descriptivos que indiquen el propósito de la variable. Evite nombres de una sola letra (excepto como contadores) y no reutilice variables para distintos propósitos.

4.2. Tipos numéricos

Python maneja tres tipos numéricos nativos: enteros (int), reales de punto flotante (float) y complejos (complex). A diferencia de muchos lenguajes, Python determina el tipo automáticamente según el valor asignado, aunque es posible convertir entre tipos de forma explícita.

# Enteros (int) — precisión arbitraria en Python
cantidad = 42
año_fundacion = 1969

# Reales (float) — la parte decimal se separa con punto
precio = 1599.99
pi_aprox = 3.14159

# Complejos (complex) — parte imaginaria con j en lugar de i
z = -1 + 2j
# Al imprimirse: (-1+2j)

# Conversión explícita de tipos
texto_ingresado = "37"
edad = int(texto_ingresado) # → 37 como entero
temperatura = float(texto_ingresado) # → 37.0 como real

4.3. Entrada y salida estándar

En Python, los datos que provienen del teclado (dispositivo de entrada estándar) se reciben siempre como cadenas de caracteres (str). Para usarlos en cálculos numéricos es obligatorio convertirlos explícitamente al tipo deseado.

# Lectura de un dato como cadena
dato_cadena = input('Ingrese un dato: ')

# Conversión a entero (dos pasos, más claro)
dato_cadena = input('Ingrese un número entero: ')
dato_entero = int(dato_cadena)

# Equivalente en un solo paso (evitar: dificulta la depuración)
# dato_entero = int(input('Ingrese un número entero: '))

# Salida estándar: print() convierte cualquier tipo a str automáticamente
print('El resultado es:', dato_entero * 2)

💡 ¿Por qué evitar componer funciones?

La expresión int(input('Ingrese: ')) compone dos funciones. Si el usuario ingresa un valor no numérico, el error ocurre en la línea compuesta y es más difícil de localizar e interpretar. Separar en dos líneas hace el código más legible y la depuración más sencilla, cumpliendo la recomendación de estilo del curso.

5. Modelo de un Programa en Python

Todo programa que resuelve un problema puede estructurarse siguiendo un modelo tipo de tres partes, resultado de la primera descomposición descendente del problema. Esta estructura es independiente del lenguaje de programación y refleja directamente las fases de Pólya.

5.1. Estructura de un programa Python tipo

'''
SECCIÓN DECLARATIVA
Descripción: Calcular el área y perímetro de un rectángulo.
Análisis de casos de prueba:
base=5, altura=3 → área=15, perímetro=16
base=7, altura=7 → área=49, perímetro=28 (cuadrado)
base=0, altura=5 → área=0, perímetro=10 (caso límite)
Recursos:
base (float): medida del lado horizontal, en metros
altura (float): medida del lado vertical, en metros
area (float): resultado del área
perimetro (float): resultado del perímetro
'''

# SECCIÓN ALGORÍTMICA

# 1. Prólogo
print('=== Calculadora de Rectángulo ===')
print('Ingrese las medidas en metros.')

# 2. Resolución
# 2.1 Ingresar datos
base_str = input('Base: ')
base = float(base_str)
altura_str = input('Altura: ')
altura = float(altura_str)

# 2.2 Calcular resultados
area = base * altura
perimetro = 2 * (base + altura)

# 3. Epílogo
print()
print('--- Resultados ---')
print('Área: ', area, 'm²')
print('Perímetro:', perimetro, 'm')

7. Python como Lenguaje de Alto Nivel

Python es un lenguaje de alto nivel: el programador escribe instrucciones cercanas al lenguaje humano, sin preocuparse por el tipo de procesador, el tamaño de las celdas de memoria ni el sistema operativo donde se ejecutará el programa.

¿Cómo llega Python a la CPU?

El código fuente Python (archivos .py) no puede ser ejecutado directamente por el hardware. El ambiente integrado de desarrollo (IDE) o el intérprete Python contiene un traductor que convierte el código fuente en instrucciones propias de la computadora donde está instalado. Por eso Python es portable: el mismo código .py funciona en Windows, Linux o macOS, siempre que exista un intérprete Python disponible.

La Python Software Foundation (PSF) administra la licencia de código abierto aprobada por OSI (Open Source Initiative), lo que hace a Python libremente utilizable y distribuible, incluso para uso comercial.

Una perspectiva que integra todos los temas

Cuando se escribe print('Hola') en Python, se activa una cadena que involucra todos los temas del curso: el intérprete Python traduce el código fuente (Tema 4); la CPU ejecuta las instrucciones de máquina resultantes siguiendo la arquitectura Von Neumann (Tema 2); el valor 'Hola' se almacena en memoria como una secuencia de bytes según la codificación de caracteres (Tema 3); y el sistema operativo gestiona tanto el proceso en ejecución como la salida hacia la pantalla (Tema 5). Cada tema del curso abre una capa más de esa cadena.
